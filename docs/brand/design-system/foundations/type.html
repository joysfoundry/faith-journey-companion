Rounder and more neutral, with a taller x-height that holds up better at 11–12px. Sits calmer next to Cormorant; gives up some personality for it.

Recommendation

Move the app to Mulish and retire Karla — not because Karla is worse in the abstract, but because this app leans hard on 11px and 12px text (eyebrows, day counts, timestamps, captions) and Mulish's x-height survives that size better. It also ends the split with the printed collateral, which is a real cost every time a new brand piece gets made. If you'd rather keep Karla, the fix runs the other way: raise the app's smallest text to 12px and change the flyer and About card to match.
