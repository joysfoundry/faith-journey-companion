Every token in src/styles.css, as it was before ACTS-148 and as it is now. All 35 existing tokens changed; 3 were added; none were removed. Swatches are painted from the literal CSS value, so what you see is what the browser resolves.

Before

Cool blue-grey paper, mid-blue primary, a yellow-ish gold nothing referenced.

After — Illuminated

Warm parchment paper, deeper Marian blue, antique gold doing real work as --accent.
