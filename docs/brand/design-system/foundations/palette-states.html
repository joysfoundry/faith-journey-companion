Oravia · Design System

Three palettes

ACTS-148 produced three palette states, not two. Only the middle one is in the beta. This card exists because a two-column “before and after” made it look as though Illuminated had shipped — it has not.

Originalsuperseded
Before ACTS-148

Cool blue-grey paper, a mid-blue primary at hue 258, and a bright yellow-gold that no component ever referenced.

Publishedlive
In the beta now

The same cool paper, with the blues and golds retuned to the exact Marian values the mark is drawn from. 16 tokens moved; surfaces untouched.

Illuminatedstaged
Designed, not shipped

The full warm system: parchment paper, gold as the section band, burgundy for liturgical marks. Recoverable with git apply stories/ACTS-148/illuminated-app.patch.

Token by token

The pattern worth seeing: in Brand and Structure, the live column already equals Illuminated — the accents are done. Everything still to change is a surface.
