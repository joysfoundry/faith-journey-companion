The painting glows because it is pigment reflecting light. A screen emits light, so the same saturation that reads luminous on canvas reads heavy after ten minutes of use. The richer column is my honest attempt at the painting’s warmth while staying comfortable for a long read — but you know how this should feel better than a contrast table does.
