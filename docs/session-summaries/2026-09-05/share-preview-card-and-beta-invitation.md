## Gotchas worth keeping
- ⚠️ **The supabase env pattern blanks the app.** `import.meta.env[…] || process.env[…]`
  is safe in `integrations/supabase/client.ts` only because that file's `VITE_*` is always
  set. `VITE_PUBLIC_URL` is normally **unset**, so the `process` arm is the *usual* path —
  and `head()` runs on every client navigation, so unguarded it throws in the **root
  route** and takes the app down. Guarded with `typeof process !== "undefined"`.
- ⚠️ **Child routes silently override the root's meta**, and `/` is what gets shared.
- **`og:image`/`og:url` must be absolute** — every platform drops a relative path silently.
- **Scrapers cache hard.** `?v=1` on the image URL, bump on redraw; test with a fresh query
  string, never a URL already shared.
- **A centred letter-spaced label sits off-axis** — the trailing space counts in the width;
  compensate with an equal `text-indent`.
- ⚠️ **Do not write `stories/.counter` with a flat number.** Doing so clobbered a
  concurrent session's bump past 161/162; it is now derived from the highest story file
  that actually exists.
