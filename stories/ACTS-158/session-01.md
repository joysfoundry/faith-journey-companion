## Gotchas worth keeping
- ⚠️ **The supabase env pattern blanks the app.** Copying
  `import.meta.env[…] || process.env[…]` from `integrations/supabase/client.ts` verbatim
  looks safe because that file's `VITE_*` value is always set, so its `process` arm never
  evaluates in the browser. `VITE_PUBLIC_URL` is normally **unset**, making that arm the
  *usual* path — and `head()` runs on every client navigation, so unguarded it throws in
  the **root route** and takes the whole app down. Now behind `typeof process !== "undefined"`.
- ⚠️ **Child routes silently override the root's meta.** Home's own `og:title` was what
  actually appeared in the iMessage screenshot, and its shorter `og:description` was
  dropping the "free beta, no account needed" line from every share of `/` — the whole
  point of the card. Home now carries the tagline and inherits the root blurb.
- **`og:image`/`og:url` must be absolute.** Every platform drops a relative path silently.
- **Scrapers cache hard.** Hence `?v=1` on the image URL — bump it on any redraw. Testing
  a URL that has already been shared shows the *old* preview; use a fresh query string.
- **A centred letter-spaced label sits off-axis** — the trailing space counts in the
  width. Compensate with an equal `text-indent`.
- **Copy sweeps are brand-only.** "Calm" was left in `seed.ts` (a Nativity reflection —
  devotional content) and `themes.ts` (a **keyword** in the peace matcher; deleting it
  would stop reflections using the word from matching). Confirmed by JC.
